# Hey, I'm Benny

I build games and tools. Right now I'm working on two things.

## Voxel factory game

A factory builder with an apothecary aesthetic. You mine, you haul, you automate. Instead of iron plates and conveyor belts, you're distilling reagents and running alembics. Everything is voxels, so the machines you build are things you can walk through and take apart.

The goal is a factory game that feels like a workshop instead of a spreadsheet.

## AI 3D model generator

A tool that generates Blockbench-ready models from a prompt. Blockbench is great, but blocking out fifty props by hand is slow. This takes a description and gives you geometry you can open, edit, and texture like anything else you made.

It stays close to the Minecraft format on purpose. Low poly count, texture-driven detail, no cleanup pass required before it's usable.
